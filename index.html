🛡️ Gestão de Identidade e Políticas de Grupo (GPO)
Apresentador: Gilvan
👤 1. Precisa ser feito
Exigir senhas fortes de 8 dígitos e bloquear a conta após 5 tentativas incorretas.
↓
⚙️ 2. Como fazer
gpmc.msc ➔ Domain ➔ Default Domain Policy ➔ Edit ➔ Computer Configuration ➔ Policies ➔ Windows Settings ➔ Security Settings ➔ Account Policies (Password & Account Lockout Policy).
↓
✉️ 3. Como testar
Auditar a política no Prompt de Comando (CMD):
net accounts
👤 1. Precisa ser feito
Bloquear pendrives USB e o Prompt de Comando (CMD/PowerShell) para impedir execução de scripts e vazamento de dados.
↓
⚙️ 2. Como fazer
gpmc.msc ➔ GPO_Seguranca_e_Padronizacao ➔ Edit:
• USB: Computer Config ➔ Admin Templates ➔ System ➔ Removable Storage Access ➔ Deny all access.
• CMD: User Config ➔ Admin Templates ➔ System ➔ "Prevent access to the command prompt" ➔ Enabled.
↓
✉️ 3. Como testar
Conectar pendrive ou abrir CMD como usuário comum:
🚫 "The command prompt has been disabled by your administrator."
👤 1. Precisa ser feito
Fixar wallpaper padrão e garantir acesso livre total para a equipe de TI.
↓
⚙️ 2. Como fazer
gpmc.msc ➔ Group Policy Objects:
• Wallpaper: Right-click em GPO_Seguranca_e_Padronizacao ➔ Edit ➔ User Config ➔ Policies ➔ Admin Templates ➔ Desktop ➔ Desktop ➔ Desktop Wallpaper: \\SRV-DC01\Dados\Publico\wallpaper.jpg
• Exceção TI: Clicar em GPO_Seguranca_e_Padronizacao ➔ Aba Delegation ➔ Advanced ➔ Domain Admins ➔ Desmarcar "Apply group policy".
↓
✉️ 3. Como testar
Checar diretivas aplicadas no cliente:
gpresult /r
📁 Servidor de Arquivos e Permissões Departamentais
Apresentador: Mariane
👤 1. Precisa ser feito
Criar as 8 pastas departamentais em C:\Dados e compartilhá-las na rede como \\esperancadigital.local\Dados.
↓
⚙️ 2. Como fazer
• Pastas: Criar em C:\Dados (Diretoria, Coordenacao, Secretaria, Biblioteca, Recepcao, Professores, Alunos, Publico).
• Share: Server Manager ➔ File and Storage Services ➔ Shares ➔ New Share (SMB - Quick) ➔ Path: C:\Dados ➔ Share Name: "Dados".
↓
✉️ 3. Como testar
Abrir no Windows Explorer de qualquer máquina:
\\esperancadigital.local\Dados
✓ Todas as 8 pastas aparecem visíveis na tela.
👤 1. Precisa ser feito
Permitir que cada usuário leia, crie e edite arquivos apenas na pasta do seu departamento.
↓
⚙️ 2. Como fazer
Right-click na pasta (ex: Secretaria) ➔ Properties ➔ Security ➔ Advanced ➔ Disable inheritance ("Convert...") ➔ Remove Users ➔ Add: "GG_Secretaria" ➔ Permission: Modify.
↓
✉️ 3. Como testar
Logado como sec.usuario, abrir seu setor:
\\esperancadigital.local\Dados\Secretaria
✓ Acesso liberado para ler, criar e salvar arquivos.
👤 1. Precisa ser feito
Bloquear o acesso a pastas de outros setores exibindo o pop-up de Acesso Negado.
↓
⚙️ 2. Como fazer
Server Manager ➔ File and Storage Services ➔ Shares ➔ Right-click "Dados" ➔ Properties ➔ Settings ➔ Uncheck "Enable access-based enumeration".
↓
✉️ 3. Como testar
Logado como sec.usuario, tentar abrir Diretoria:
\\esperancadigital.local\Dados\Diretoria
🚫 Pop-up: "Network Error: Access is denied".
🖨️ Servidor de Impressão e Fila Geral Centralizada
Apresentador: Edmar
👤 1. Precisa ser feito
Habilitar o serviço central de impressão no Windows Server 2022.
↓
⚙️ 2. Como fazer
Server Manager ➔ Manage ➔ Add Roles and Features ➔ Server Roles ➔ Print and Document Services ➔ Role Services: Print Server ➔ Install.
↓
✉️ 3. Como testar
Abrir console de gerenciamento de impressão:
printmanagement.msc
✓ Print Servers ➔ SRV-DC01 ativo e operacional.
👤 1. Precisa ser feito
Criar a fila corporativa IMP_Geral no IP 192.168.10.20 publicada no AD.
↓
⚙️ 2. Como fazer
printmanagement.msc ➔ Print Servers ➔ SRV-DC01 ➔ Right-click "Printers" ➔ Add Printer... ➔ TCP/IP (192.168.10.20) ➔ Nome: IMP_Geral ➔ Marcar "Share this printer" e "List in the directory".
↓
✉️ 3. Como testar
Conectar na impressora pela rede da estação:
\\SRV-DC01\IMP_Geral
✓ Fila pronta para receber impressões de todos os setores.
👤 1. Precisa ser feito
Corrigir erro de conexão remota 0x8007011b para permitir impressão direta das estações.
↓
⚙️ 2. Como fazer
PowerShell (Admin): New-ItemProperty -Path "HKLM:\System\CurrentControlSet\Control\Print" -Name "RpcAuthnLevelPrivacyEnabled" -Value 0 -PropertyType DWORD -Force; Restart-Service Spooler.
↓
✉️ 3. Como testar
No cliente: Right-click em IMP_Geral ➔ Properties ➔ Print Test Page:
✓ Página de teste impressa sem travar.
🛡️ Windows Defender Firewall & Conectividade de Rede
Apresentador: Adler
👤 1. Precisa ser feito
Manter o Firewall ativo nos 3 perfis (Domain, Private e Public) para segurança da rede.
↓
⚙️ 2. Como fazer
wf.msc ➔ Windows Defender Firewall Properties ➔ Abas "Domain", "Private" e "Public Profile" ➔ Firewall state: "On (recommended)".
↓
✉️ 3. Como testar
Checar status de proteção no console:
wf.msc
✓ Status verde ativo em Domain, Private e Public.
👤 1. Precisa ser feito
Liberar o tráfego para compartilhamento SMB (Porta 445) e resposta a testes de Ping.
↓
⚙️ 2. Como fazer
wf.msc ➔ Inbound Rules ➔ Habilitar (Enable Rule):
• "File and Printer Sharing (SMB-In)"
• "File and Printer Sharing (Echo Request - ICMPv4-In)".
↓
✉️ 3. Como testar
Disparar Ping da estação para o servidor:
ping 192.168.10.2
✓ 0% de perda com latência <1ms.
👤 1. Precisa ser feito
Criar a resolução de DNS Reverso para resolver o IP 192.168.10.2 e evitar lentidão no logon.
↓
⚙️ 2. Como fazer
dnsmgmt.msc ➔ SRV-DC01 ➔ Reverse Lookup Zones ➔ New Zone... ➔ Primary (IPv4: 192.168.10) ➔ New Pointer (PTR): IP .2 ➔ SRV-DC01.esperancadigital.local.
↓
✉️ 3. Como testar
Validar resolução reversa no Prompt (CMD):
nslookup 192.168.10.2
✓ Retorna: SRV-DC01.esperancadigital.local.
